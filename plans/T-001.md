# T-001: Port test1 to Python 3 and add pytest tests

**Agent:** whale  **Branch:** `task/T-001`  **Base:** `master`

## Goal
`test1` is a small toy Python project written for Python 2. `main.py` uses `print` statements, so it doesn't run on Python 3, and there are no tests. Make it run on Python 3 with **no change in behavior**, and add a small pytest suite. This is also the first end-to-end test of the Buzz task workflow, so follow the status protocol exactly.

## Scope
Files and areas to change:
- `main.py`: convert the `print` statements to `print()` calls, and replace `from pkg1 import *` with explicit imports. Output must stay identical (see Test).
- `pkg1/*.py`, `pkg2/*.py`: change only what Python 3 requires (probably nothing). Keep the function names and return values exactly as they are, including the differences between packages: `pkg1.p1.mysquare(5)` returns the string `"Square: 5"`, and `pkg2.p1.mysquare(5)` returns `25`.
- New `tests/test_packages.py`: pytest tests for all four functions, plus one test that runs `main.py` as a subprocess and checks its exact output.
- New `requirements-dev.txt` containing `pytest`.
- `README.md`: add a short "Run and test" section with the commands below.

Do not touch:
- `.idea/`, the IDE config
- Function names or return values in `pkg1` and `pkg2`

## Steps
1. Check out `task/T-001` and read this plan and the README.
2. Port `main.py` to Python 3.
3. Add the tests and `requirements-dev.txt`.
4. Update the README.
5. Run the Test commands until they pass.
6. Commit in small steps, push, and open the PR against `master`.

## Conventions
- Python 3.10+ standard library only, plus pytest for tests.
- Work in a virtual environment: `python3 -m venv .venv && . .venv/bin/activate && pip install -r requirements-dev.txt`. Add `.venv/` to a new `.gitignore`.

## Test
```bash
python3 main.py
python3 -m pytest -q
```
`python3 main.py` must print exactly:
```
Square: 5
Sum 5
25
10
it's done
```

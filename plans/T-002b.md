## Steps
1. Create `pkg2/spread.py` with these three functions. Each takes any iterable of ints or floats and gives it a one-line docstring.
   - `value_range(values)`: `max - min`. It's named `value_range` so it doesn't shadow the built-in `range`.
   - `variance(values, sample=False) -> float`: the population variance by default (divide by n). With `sample=True`, the sample variance (divide by n − 1).
   - `stdev(values, sample=False) -> float`: the square root of `variance(values, sample)`. Use `math.sqrt`.
   - Each function turns its input into a list first, so generators work.
   - An empty input raises `ValueError` with a message containing `empty`.
   - `sample=True` with fewer than two values raises `ValueError` with a message containing `two`.
   - Compute the mean inside this module (a small private helper is fine).
   - Use only the standard library, and **don't** use the `statistics` module in `pkg2/spread.py`.
2. Create `tests/test_spread.py` with pytest tests that cover:
   - `value_range` on ints, floats and negatives, and a single value (range 0);
   - population and sample `variance` and `stdev` (use `pytest.approx`);
   - a single value: population variance is `0.0`, and sample variance raises `ValueError`;
   - a generator as input;
   - `ValueError` on empty input for all three functions (`pytest.raises(ValueError, match="empty")`);
   - a cross-check against Python's `statistics.pvariance`, `statistics.variance`, `statistics.pstdev` and `statistics.stdev` on a few lists. The `statistics` module is allowed in the tests.
3. Commit in small, logical commits and push to `task/T-002b`.

## Steps
1. Create `pkg2/central.py` with these three functions. Each takes any iterable of ints or floats and gives it a one-line docstring.
   - `mean(values) -> float`: the arithmetic mean.
   - `median(values) -> float`: the middle value of the sorted values. With an even count, the average of the two middle values. Always return a float, for example `median([1, 3, 2]) == 2.0`.
   - `mode(values)`: the most common value. If several values tie, return the **smallest** of them, for example `mode([1, 2, 2, 3, 3]) == 2`.
   - Each function turns its input into a list first, so generators work.
   - An empty input raises `ValueError` with a message containing `empty`.
   - Use only the standard library, and **don't** use the `statistics` module in `pkg2/central.py`. Write the arithmetic yourself. `collections.Counter` is fine.
2. Create `tests/test_central.py` with pytest tests that cover:
   - odd and even counts for `median`, and unsorted input;
   - negative numbers and floats (use `pytest.approx` for floats);
   - a generator as input;
   - the tie rule for `mode`;
   - `ValueError` on empty input for all three functions (`pytest.raises(ValueError, match="empty")`);
   - a cross-check against Python's `statistics.mean`, `statistics.median` and `statistics.mode` on a few lists without ties. The `statistics` module is allowed in the tests.
3. Commit in small, logical commits and push to `task/T-002a`.
